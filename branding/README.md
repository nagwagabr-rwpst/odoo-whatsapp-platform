# RelayRuntime Branding Kit

Canonical official brand assets for RelayRuntime (hexagonal identity).

## Files

| File | Use |
|------|-----|
| AppIcon.svg / AppIcon.png | Favicon, mobile mark, module icon, diagrams |
| HorizontalLogo.svg / HorizontalLogo.png | Navigation, footer, social/meta |
| VerticalLogo.svg / VerticalLogo.png | Vertical placements, store packs |

## Sync targets

- `landing-page/assets/` — web marketing site
- `relayruntime/static/description/` — Odoo Apps packaging

Do **not** add legacy `icon.png` / `icon.svg` / JPG logos here.
