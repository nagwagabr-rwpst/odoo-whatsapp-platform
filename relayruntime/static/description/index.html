RelayRuntime – Enterprise WhatsApp Messaging for Odoo Community

Odoo WhatsApp Integration as an Enterprise Messaging Platform

Module version 19.0.6.1.0 · Odoo 19 Community · License LGPL-3

RelayRuntime is an Enterprise Messaging Runtime for operators who need more than a WhatsApp Connector for Odoo. It combines WhatsApp Business Integration with durable execution, observability, and Multi-Provider WhatsApp control.

Overview

RelayRuntime delivers WhatsApp Integration for Odoo Community through a clear WhatsApp API abstraction and a practical Odoo WhatsApp API surface. Teams use it for Business Messaging and Customer Communication without rewriting operational workflows when a gateway changes.

Beyond basic send actions, the runtime supports WhatsApp Messaging with WhatsApp Automation, Bulk Messaging, Campaign Management, Scheduled Messages, Message Templates, and Delivery Tracking, so day-to-day work stays measurable under operator control.

Enterprise UI

  • Command Center with KPIs, alerts, and workspaces
  • Enterprise navigation: Operations / Analytics / Configuration
  • Delivery Dashboard and Live Campaign Monitor
  • RWPST brand theme across backend screens

Enterprise capabilities

  • Safe recovery and automatic reconciliation of interrupted runs
  • Resilient batch execution with durable outbound tracking
  • Controlled worker coordination with live heartbeat monitoring
  • Retry tracking across parent and child campaigns
  • Attachment and product catalog support
  • Operational visibility through message logs and execution history

Features

  • Launch Bulk Messaging from contacts with attachments and product catalogs
  • Plan and monitor Campaign Management with live execution visibility
  • Use Scheduled Messages for timed outbound operations
  • Follow Delivery Tracking across sent, failed, and skipped outcomes
  • Retry failed or skipped recipients as follow-up campaigns
  • Operate outbound work through a durable Message Queue
  • Keep Message Templates consistent across operational Notifications
  • Review campaign analytics, success rates, and runtime KPIs

An external provider account is required for live delivery. Mock Provider is included for safe testing without sending real messages.

Supported Providers

Connect production gateways through Multi Provider adapters for Meta Cloud API, Evolution API, and Green API.

Mock Provider is available for development, demonstrations, and testing without sending real WhatsApp messages.

Limitations

This module does not guarantee exactly-once delivery to WhatsApp. External provider services and retry campaigns can occasionally produce duplicate messages. Very large bulk sends may take longer and can approach server time limits.

  • No built-in background queue for unattended bulk processing
  • Inbound message webhooks are not fully available in this release
  • Live delivery depends on your configured WhatsApp provider account
  • Multi-worker deployments require careful operational planning

Installation

Configure your preferred WhatsApp Messaging provider from WhatsApp → Settings.

Green API, Meta Cloud API, or Evolution API can be used depending on your Multi Provider setup. Green API is a common production choice.

Mock Provider is intended for testing and development environments.
