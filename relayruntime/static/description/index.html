RWPST RelayRuntime

Enterprise Command Center for operational messaging on Odoo 19

Module version 19.0.6.1.0 · Odoo 19 Community · License LGPL-3

Overview

RWPST RelayRuntime is an Enterprise Messaging Runtime for Odoo Community, providing a unified Command Center for reliable operational messaging, campaign execution, provider management, and delivery monitoring.

Built for production environments, RelayRuntime helps businesses execute messaging operations with resilience, operational visibility, and enterprise-grade workflow integration.

Enterprise UI

  • Command Center with KPIs, alerts, and workspaces
  • Enterprise navigation: Operations / Analytics / Configuration
  • Delivery Dashboard and Live Campaign Monitor
  • RWPST brand theme across backend screens

Enterprise capabilities

  • Safe recovery and automatic reconciliation of interrupted runs
  • Resilient batch execution with durable outbound tracking
  • Controlled worker coordination with live heartbeat monitoring
  • Retry tracking across parent and child campaigns
  • Attachment and product catalog support
  • Operational visibility through message logs and execution history

Features

  • Bulk send from Contacts with attachments and product catalogs
  • Live campaign monitor with automatic refresh
  • Retry failed or skipped recipients as follow-up campaigns
  • Delivery logs, dashboards, and sales order workflow integration
  • Supported providers: Green API and Mock Provider
  • Mock Provider for safe testing without sending real WhatsApp messages

An external WhatsApp provider account (for example Green API) is required for live delivery. Mock Provider is included for safe testing.

Supported Providers

Production-ready Green API integration is included for live WhatsApp delivery.

Mock Provider is available for development, demonstrations, and testing without sending real messages.

Limitations

This module does not guarantee exactly-once delivery to WhatsApp. External provider services and retry campaigns can occasionally produce duplicate messages. Very large bulk sends may take longer and can approach server time limits.

  • No built-in background queue for unattended bulk processing
  • Inbound message webhooks are not fully available in this release
  • Only Green API and Mock Provider support live or test sending
  • Multi-worker deployments require careful operational planning
