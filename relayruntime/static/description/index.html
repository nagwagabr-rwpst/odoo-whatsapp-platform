FAQ

What providers are supported?

Meta Cloud API, Evolution API, and Green API, plus Mock Provider for safe testing. The runtime is designed for future adapters as well.

Can I switch providers?

Yes. RelayRuntime abstracts providers, so you can change adapters without rebuilding campaigns, templates, or operator workflows.

Does it support Odoo Community?

Yes. RelayRuntime is built for Odoo Community as an Enterprise Messaging Runtime.

Does it support bulk messaging?

Yes. Bulk Messaging and Campaign Management are first-class operator workflows, including attachments, product catalogs, and Scheduled Messages.

Can I monitor delivery?

Yes. The Delivery Dashboard provides Delivery Tracking for sent, failed, and skipped outcomes, with Message Queue and Retry visibility.

Is this just a WhatsApp connector?

No. RelayRuntime is an Enterprise Messaging Runtime—queue, retry, campaigns, analytics, and Multi Provider control—not a simple sender.

Limitations

This module does not guarantee exactly-once delivery to WhatsApp. External provider services and retry campaigns can occasionally produce duplicate messages. Very large bulk sends may take longer and can approach server time limits.

  • No built-in background queue for unattended bulk processing
  • Inbound message webhooks are not fully available in this release
  • Live delivery depends on your configured WhatsApp provider account
  • Multi-worker deployments require careful operational planning

Installation

Configure your preferred provider from WhatsApp → Settings. Use Mock Provider for testing, then connect Meta Cloud API, Evolution API, or Green API for live delivery.
