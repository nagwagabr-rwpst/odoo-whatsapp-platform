# RelayRuntime — Brand Voice Guide

**Status:** Authoritative  
**Companion to:** `Product_Messaging_Guide.md`  
**Purpose:** Define how RelayRuntime sounds in every channel.

---

## 1. Tone of voice

RelayRuntime speaks with five constants:

| Trait | Meaning in practice |
|-------|---------------------|
| **Professional** | Business language. No slang, no memes, no emoji-led copy. |
| **Enterprise** | Talk like a production system vendor, not an app store gadget. |
| **Confident** | State what the product is. Do not apologize or over-qualify. |
| **Technical** | Accurate terms: runtime, queue, retry, providers, delivery outcomes. |
| **Clear** | Short sentences. Concrete nouns. One idea per line when possible. |

**No hype.**

Avoid: revolutionary, amazing, game-changing, ultimate, magical, forever, #1, crushing competitors.

## 2. Brand personality

RelayRuntime is:

- Calm under operational pressure  
- Precise about outcomes  
- Respectful of operators and partners  
- Serious about reliability  
- Open about limitations when required  

RelayRuntime is not:

- Loud  
- Salesy  
- Gimmicky  
- Vague  
- Over-promising  

---

## 3. Voice principles

### Lead with category

Always establish **Enterprise Messaging Runtime for Odoo Community** before listing features.

### Sell outcomes, then capabilities, then features

Wrong: “We have 11 features including templates.”  
Right: “Operators can prove delivery and recover failed recipients—using Campaign Management, Delivery Dashboard, and Retry.”

### Prefer verbs of control

Prefer: run, monitor, recover, abstract, track, operate, prove.  
Avoid: blast, spam, hack, supercharge, unlock unlimited.

### Name providers as adapters

Say: “Multi-Provider adapters including Meta Cloud API, Evolution API, and Green API.”  
Do not: center the product name around one vendor.

### Stay honest

Never claim exactly-once delivery.  
Never claim inbound chat/bot completeness if not shipped.  
Never claim Odoo Enterprise exclusivity—RelayRuntime targets **Odoo Community**.

## 4. Channel adaptation

Same message. Different length.

| Channel | Style |
|---------|-------|
| Odoo Apps | Conversion-first, scannable sections, value then proof |
| Website | Brand-forward, structured sections, demo CTA |
| LinkedIn | Professional insight + clear category, no hype |
| YouTube | SEO clarity in title; runtime positioning in description |
| Documentation | Precise, operational, zero marketing adjectives |
| Blog | Educate on problems (reliability, providers, operations) |
| GitHub | Technical honesty; product category in README opening |
| Presentations | Pyramid: mission → value → capabilities → features |
| Demo / VO | Calm, mid-tempo; “runtime,” “execution,” “operators” |
| Sales material | Persona-specific outcomes; objection handling via FAQ truth |

---

## 5. Grammar and style

- American English spelling in commercial copy unless localized.  
- Prefer **RelayRuntime** (one word, capital R twice).  
- Prefer **Odoo Community** over vague “Odoo.”  
- Use en dash or hyphen consistently in titles; avoid decorative symbols.  
- Use “Multi-Provider” or “Multi Provider” consistently within one asset.  
- Prefer active voice.  
- Numbers: use digits for metrics; spell out one–nine in prose when stylistic.

## 6. Do / Don’t examples

### Positioning

| Do | Don’t |
|----|-------|
| Enterprise Messaging Runtime for Odoo Community | Simple WhatsApp module for Odoo |
| More than a WhatsApp connector—a runtime | The best WhatsApp connector |
| Provider abstraction with Multi-Provider control | Works with WhatsApp (only) |

### Features vs value

| Do | Don’t |
|----|-------|
| Prove what was delivered with the Delivery Dashboard | Amazing analytics dashboard!!! |
| Recover failed recipients with the Retry engine | Never lose a message (absolute claim) |
| Switch providers without rewriting workflows | Unlimited providers forever |

### Audience

| Do | Don’t |
|----|-------|
| Built for operators and partners on Community | Made for everyone who loves chatting |
| Campaign operations and delivery truth | Fun chat experiences |

## 7. Visual language (copy adjacent)

When writing captions, titles, or lower-thirds:

- Prefer: Command Center, Delivery Dashboard, Bulk Messaging, Provider Management, Campaign Analytics  
- Avoid: Generic “screenshot 1,” “settings page,” “dashboard image”  
- Demo on-screen text must say **Enterprise Messaging Runtime** / **Enterprise WhatsApp Messaging for Odoo Community**—never “WhatsApp Connector”

## 8. Approval checklist

Before publish:

- [ ] Category correct (Runtime, not connector/chatbot)  
- [ ] Odoo Community named where platform matters

- [ ] No hype adjectives
