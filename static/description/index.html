WhatsApp Simple

Runtime-aware WhatsApp campaign execution for Odoo 19

Overview

WhatsApp Simple is an Odoo 19 Community module for outbound WhatsApp campaigns with execution attempts, lease-based concurrency control, recipient idempotency, and operational documentation — not merely a one-shot sender.

Bulk sends run synchronously in the user request. Each run creates a durable whatsapp.bulk.execution record with heartbeat and lease metadata. Campaigns remain the business-facing aggregate; executions are the runtime authority.

Architecture positioning

  • Provider adapter layer (Green API + Mock for production use today)
  • Execution-attempt model with immutable UUID per run
  • Campaign-scoped idempotency and retry fingerprint deduplication
  • Outbound intent flush before provider HTTP (same-transaction)
  • Stale execution reconciliation

Operational capabilities

  • Bulk send from Contacts with attachments and product catalogs
  • Campaign monitor (kanban, periodic refresh)
  • Retry failed/skipped recipients (child campaigns)
  • Delivery logs, dashboard, sale order workflow
  • Mock Provider for QA without real messages

Limitations (read before production)

This module does not guarantee exactly-once delivery to WhatsApp. Provider APIs are external to PostgreSQL; HTTP rollbacks and retry campaigns can produce duplicate messages. Large bulks run in a single long transaction and may hit server timeouts.

  • No built-in background queue or cron bulk worker
  • No inbound webhook HTTP controllers (skeleton only)
  • Most alternate providers are UI placeholders — Green API and Mock are send-capable
  • Multi-worker deployments should follow production checklist in documentation

Deployment notes

  • Odoo 19.0 Community (module version 19.0.5.5.0)
  • Dependencies: base, sale, mail, product
  • Configure WhatsApp → Settings (Mock for testing, Green API for live)
  • Review limit_time_real and worker count for campaign size
  • Full documentation shipped in docs/ inside the module
